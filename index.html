Moje projekty

Zbierka malých programov v Pythone a čistom HTML/CSS/JavaScripte. Webové projekty nepotrebujú žiadne knižnice ani inštaláciu – stačí otvoriť súbor v prehliadači.

Pohybuj myšou po stránke – bodky sa od nej odtláčajú.

🐍 Python

SúborPopis
faktorial.pyVýpočet faktoriálu cyklom aj rekurziou, s kontrolou vstupu a porovnaním s math.factorial.
generator_hesiel.pyGenerátor bezpečných hesiel cez modul secrets. Voliteľná dĺžka (4–128) a typy znakov.
kalkulacka.pyKonzolová kalkulačka (+ - * / ** %) s desatinnou čiarkou a pokračovaním od posledného výsledku.

Spustenie

Vyžaduje Python pre spustenie.

python faktorial.py
python generator_hesiel.py
python kalkulacka.py
